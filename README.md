One line, under 200 characters, of a joke about a meeting that should have been an email. A model judge reads two entries at a time and keeps the funnier one.

## Run it

```sh
python3 main.py
```

The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `output/entry.txt` when the variable is not set). It validates the line first — 1 to 200 characters, not only whitespace, a single line — then writes it in plain text mode with no trailing newline, and reads it back to confirm the words match.

Entry: "We scheduled a meeting to discuss why we have too many meetings. The meeting ran over. We scheduled another one." (112 characters, one line.)
